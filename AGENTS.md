# AI Agent Instructions

## Project Context
Before making code changes, read README.md to understand:
- The project's purpose
- Architecture and dependencies
- Existing features and functionality

Treat README.md as the primary source of project context.

## Development Rules
- Preserve existing functionality unless explicitly asked to change it.
- Follow established architectural patterns.
- Reuse existing utilities before creating new ones.
- Avoid introducing unnecessary dependencies.
- Develop in a way that allows for optionality and agility. Nothing is set in stone. A change or added feature shouldnt require a massive refactor.
- Run basic and relevant tests after modifications.
- Update README.md when architectural or functional changes occur.
